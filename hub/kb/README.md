# Base de conocimiento (RAG)

Estos documentos son lo que el asistente del capitán consulta con `search_knowledge`.

- Añade ficheros `.md` o `.txt` en esta carpeta: en español, factuales, con una línea `Fuente:` al final.
- Desde `hub/`, ejecuta `npm run ingest`. Vuelve a incrustar cada fichero y reemplaza sus fragmentos anteriores.
- Este README no se indexa.
